# References

The principal source is:

Tadeusz Balaban, **Propagators for lattice gauge theories in a background field**, *Communications in Mathematical Physics* **99** (1985), 389–434. The coercivity lower bound appears on p. 428.

Related sources include Balaban’s CMP 95/96 propagator papers, CMP 98 averaging paper, CMP 99 gauge-fixing paper, and CMP 109 renormalization-group paper.

[`source-manifest.tsv`](source-manifest.tsv) maps formal files to the source documents and pages they cite, with document hashes. [`not-located.txt`](not-located.txt) lists unresolved source references. Consult the original publications for the texts; they are not required to run the Lean build.
