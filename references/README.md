# Bibliographic source metadata

The principal source is:

Tadeusz Balaban, **Propagators for lattice gauge theories in a background field**, *Communications in Mathematical Physics* **99** (1985), 389–434; the coercivity lower bound is on p. 428.

Related Balaban sources used in the development include the CMP 95/96 propagator papers, CMP 98 averaging paper, CMP 99 gauge-fixing paper, and CMP 109 renormalization-group paper. The source-manifest filenames distinguish these publications. The draft paper is not part of this public release.

[`source-manifest.tsv`](source-manifest.tsv) preserves bibliographic/provenance metadata from the private working corpus: historical citation paths, the paths of the corresponding source files in that corpus, their SHA-256 hashes, and the formal files that cite them. **The paths identify excluded private source material; they are not promises that those PDFs, page images, or transcriptions are distributed here.** [`not-located.txt`](not-located.txt) records historical unresolved source references.

The public release does not redistribute the six source PDFs, full-page Markdown transcriptions, or page-image copies. Consult the original publications through their publishers or appropriate scholarly repositories. These materials are not required to run the Lean build.

The project’s CC BY-SA license applies to its original material, not to third-party source publications. Original analysis may contain short attributed quotations; that does not grant redistribution rights to entire source documents.
