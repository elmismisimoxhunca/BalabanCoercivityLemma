# Historical workflow definitions

These JavaScript files are the research orchestration specifications formerly stored in the private workspace’s `.bb/workflows/` directory. They are published as process provenance, not as active automations or proof certificates.

They contain historical model names, task prompts, workspace paths, and review protocols. They are not turnkey scripts for a fresh clone, do not include credentials or private conversation transcripts, and are not run by `REPRODUCE.sh`. A workflow’s requested deliverable is not evidence that it was achieved; consult the corresponding research report and retained compile evidence.

Mathematical proof search is paused. Publishing these files does not schedule another run.
