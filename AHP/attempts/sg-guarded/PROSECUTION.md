## Findings

**F1 (substantive wording error — must fix).** The note's pin section states: "`GuardPencilT` fails if and only if some configuration in the headline prefix has `Shift` such that … . One exterior path that starts in class, with one positive-energy test field, and that hits such a parameter, is enough to refute it." This misstates the refutation criterion. `GuardPencilT` asserts the transfer only *eventually* in `m` and `R` (`∃ m₀ ∀ m ≥ m₀ ∃ R₀ ∀ R ≥ R₀`). Its negation is the dualised, cofinal family: for some `ell, a`, for **every** `m₀` an `m ≥ m₀`, for **every** `R₀` an `R ≥ R₀`, for every `a₀` a bad configuration. That is exactly the quantifier shape of the frozen `SepPathFamily2` (`DrFamily2.lean:36`), which the same note cites one paragraph later as "the negation shape". A single exterior path at one `(m, R)` does **not** refute `GuardPencilT`: one bad instance only kills one threshold choice, and the statement can still hold with larger thresholds. The note's own Obstruction section has the correct shape ("one exterior path, at arbitrarily large scales"), so the pin-section sentences contradict the note itself. The "if and only if" is wrong in both directions as written: pointwise failure does not imply global failure, and global failure requires cofinally many pointwise failures. Required fix: replace the two sentences with the dualised criterion (equivalently: "`GuardPencilT` fails iff the cofinal family version of the pin holds; `SepPathFamily2` is the named shape of that family; one path at one scale refutes nothing"). This error does not change the outcome (still undecided), but as written it hands a referee a false shortcut to a refutation.

**F2 (minor wording — should fix).** The note attributes to `domination_fails_pi` that "the totalized corrected form is not positive semidefinite". The theorem's type (`GdR6a.lean:109`) is: at `U_π` (in class), `∃ v, ⟪v, Ginv_lit v⟫ < 0 ∧ 0 ≤ ⟪v, Ginv_loc v⟫` — the second conjunct is about the **localised literal** `Ginv` (`dataS selIn selIn … .Ginv`), not a "corrected" (`G1inv`) or "totalized" form. The reading "`G1inv_lit − G1inv_loc` is not psd" is available only as the module docstring's corollary through `G1inv_diff_eq`, not from `domination_fails_pi` alone. The note's conclusions from it ("Units at `π` are not proved. Indefinite is not singular. This is not a pencil non-unit.") are correct; only the paraphrase of the type is off.

**F3 (minor citation slip).** `pencil_bracket_unit` lives in `DrBracket2.lean:20`, not `D1IVT.lean`; the note's sentence "already `exists_nonunit_path` (`lean/src/D1IVT.lean`) and `pencil_bracket_unit`" attaches the file citation ambiguously and will send a reader to the wrong file for the bracket lemma.
