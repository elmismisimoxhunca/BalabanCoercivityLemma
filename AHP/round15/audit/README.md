The records concern explicit matrix identities and conditional reductions for an all-plaquette formulation. They do not establish identification with the physical operators or the existence of a nonzero-area kernel vector.

## Mathematical scope

The calculations include exact arithmetic checks of 336 transcribed character blocks and high-precision area calculations for \(q=1,2,4\), with even \(R=18,\ldots,40\). There is also a held-out \(q=1,R=42\) calculation; no result is asserted for \(q=2,R=42\).

The formulation assuming only existence of the first inverse remains formally open. The operator identification, nonzero-area premise, and cofinal argument are unresolved. The formulation with all inverse-existence assumptions is a separate proved statement.
