For Omega_0 itself ymx's cell weights (I:45439 ff.) treat a bond with one end-point outside Omega_0 as a bond of the domain (weight 1 on the one inner block).
   Help: this is a printed source for the TOUCHING mask (at least one end-point / one corner). It is stated in CMP102, not CMP99, but CMP99 sits on it. 2. **CMP109 eq. (1.12) is NOT an "all cubes up to a size" class. Printed text supports ymx's worry, not their reading. VERIFIED on page image (CMP109 p.262, PDF p.14).**
   Verbatim (1.11)-(1.12): "(i) U = U'U, U has values in the group G, |dU - 1| < alpha_0 xi^2 on X, for each cube [box] subset X of a size O(1)LM there exists a G-valued gauge transformation u defined on [box] and such, that U^u = exp i xi A, |A|, |nabla^xi A| < O(1)LM B alpha_0 on [box], with a sufficiently large constant B (it will be determined later)."
   - Same grammar as CMP99 p.396 ("for an arbitrary cube of the described above class ... where O(1)M is a size of the cube"). It speaks of cubes "of a size O(1)LM", with no "at most" and no "every smaller cube". So CMP109 does not quantify over all sub-cubes, and it is not a printed source for our coverage hypothesis.
   - ymx admits the reading is theirs: I:4447 "the phrase 'for each cube subset X of a size O(1)LM' is read as 'for each cube subset X of a size at most oLM'." and I:4601-4606: under the exact-size reading "(1.12) is void on a domain X too thin to contain such a cube".
   - What the printed text does show. (a) X is a localization domain: a connected finite union of M-cubes (CMP109 p.257: "a union of a connected, finite family of cubes from pi_j"; connected = common wall). So a size-O(1)LM cube inside X exists only if X is wide enough, and nothing says every bond of X lies in one. (b) The condition is quantified over every cube of that size inside X, not over a nest-indexed class as in CMP99 p.396. Positions of the cubes are free. That is closer to our "union class" statement, but the bond-covering step is still ours.
   - CMP119 (2.38), p.261 (page image): "(ii) For each cube [box] subset Omega_n \ Omega_{n+2}, [box] cap Omega_{n+1}^c not empty, n = 1,...,j-1, of the size CML^n xi, or [box] subset Omega_j and of the size CM, there exists a gauge transformation u defined on [box] cap X ... < B C M alpha_{0,n}". Again an exact size. It adds that u is only required on [box] cap X, so the cube need not lie in X. This is a third printed per-cube class (nest-indexed, exact size, with C a positive integer constant). It gives no coverage statement.
   Assessment: no new support for the coverage hypothesis in Balaban. But the same-grammar fact is useful for the paper: our added coverage hypothesis can be presented as the "at most" reading that a later independent reader (ymx) also had to adopt to make (1.12) non-void, with the exact-size reading explicitly named as vacuous on thin X.
